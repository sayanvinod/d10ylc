# D10YLC Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first complete, static, accessible D10YLC website for GitHub and Cloudflare Pages without presenting unresolved official facts as current.

**Architecture:** Astro generates six core routes plus policy and error pages from shared layouts and typed content modules. A minimal script controls the mobile menu; all content and primary navigation work without a client framework.

**Tech Stack:** Astro, TypeScript, Vitest, Playwright, axe-core, CSS, Cloudflare Pages

## Global Constraints

- Use the approved revamp plan and the public legacy site only as the allowed content boundary.
- Do not publish disputed eligibility, commitment, leadership, affiliation, contact, dates, or impact claims as facts.
- Use WCAG 2.2 AA as the acceptance target.
- Keep content static, portable, and free-hosting compatible.
